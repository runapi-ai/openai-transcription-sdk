## Install

```bash
npx skills add runapi-ai/openai-transcription -g
```

Or paste this prompt to your AI agent:

```text
Install the openai-transcription skill for me:

1. Clone https://github.com/runapi-ai/openai-transcription
2. Copy the skills/openai-transcription/ directory into your user-level skills directory for Claude Code, Codex, or Gemini CLI.
3. Verify that skills/openai-transcription/SKILL.md is present.
4. Confirm the install path when done.
```
